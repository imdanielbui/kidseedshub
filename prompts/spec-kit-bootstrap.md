# Prompt: Spec Kit Bootstrap

```md
Act as Spec Agent.

Goal: bootstrap spec-driven development for this project.

Create in order:
- constitution
- feature brief
- technical plan
- task breakdown

Rules:
- Keep each artifact short and executable.
- Ask up to 5 short questions only if requirements are unclear.
- Focus on traceability, acceptance criteria, and verification.
- Do not choose implementation details until the plan stage.

Output the artifacts in a compact, ready-to-save format.
```
