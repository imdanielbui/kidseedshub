# Prompt: Code Review

```md
Act as Review Agent with balanced strictness.

Review the current changes for bugs, regressions, security risks, missing tests, and maintainability issues.

Focus on:
- Auth/session and role permissions.
- Student/parent data privacy.
- API validation.
- Scheduling, attendance, payroll, and reports.
- UI states and responsive behavior.
- Test gaps.

Output findings first, ordered by severity, with file/line references. Avoid nitpicks.
```
