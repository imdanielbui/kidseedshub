# Prompt: Spec-Driven Development

```md
Act as Spec Agent.

Goal: {goal}
Users: {users}
Known constraints: {constraints}

Create:
- feature brief
- acceptance criteria
- technical plan
- task breakdown
- verification plan

Rules:
- Keep it short and executable.
- Ask up to 5 short clarifying questions only if needed.
- Highlight auth, roles, data, migration, and deployment risks.
```
