# Documentation Workflow

Use for developer docs and user/admin docs.

## Developer Docs

Include:

- Setup and env variables, without secret values.
- Architecture and module boundaries.
- API/data flow.
- Test and deployment commands.
- Known limitations.

## User/Admin Docs

Include:

- Who can perform the task.
- Step-by-step workflow.
- Required inputs.
- Expected output.
- Common errors and how to fix them.

## Rules

- Document actual behavior, not plans.
- Avoid placeholder sections.
- Keep docs task-oriented and concise.
