# Spec-Driven Development Workflow

Use this workflow for major features or anything that benefits from traceable planning.

## Steps

1. Clarify the request.
2. Write a feature brief.
3. Create a technical plan.
4. Break the work into tasks.
5. Implement one slice at a time.
6. Verify against acceptance criteria.

## Good Fit

- Auth-heavy work.
- Scheduling and reporting.
- Multi-role dashboard flows.
- API or integration work with several edge cases.
- Anything likely to generate follow-up tasks.
