# Documentation Archive

This folder is for historical plans, handoffs, screenshots notes, and specs that are no longer active operating contracts.

## Rules

- Prefer quarantine before deletion.
- Move stale docs into `docs/archive/YYYY-MM/` with a short note explaining why they were archived.
- Do not archive active contracts from `docs/ai-context/`, release checklists, migrations, or production data notes unless a replacement is already linked.
- Generated artifacts belong in ignored output folders, not in this archive.
- If an archived doc still contains an active decision, extract that decision into the relevant active contract before moving it.

## Active Docs Stay Outside Archive

- Agent context: `docs/ai-context/`
- Release gates: `docs/checklists/release-checklist.md`
- Deployment workflow: `docs/workflows/deployment-workflow.md`
- Current roadmap reference: `docs/specs/kidseedshub-full-product-plan.md`
