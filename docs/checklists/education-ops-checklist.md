# Education Operations Checklist

- Class has course, total sessions, start date, weekdays, slot, teacher, room.
- Vietnam holiday calendar is configured.
- Holiday sessions are skipped or moved according to class config.
- Generated schedule reaches required total sessions.
- Manual admin edits are preserved.
- Attendance states include present, absent with permission, absent without permission.
- Makeup eligibility is configurable.
- Teacher payroll requires admin approval.
- End-of-course report supports dashboard, PDF, Excel, and AI comments where enabled.
