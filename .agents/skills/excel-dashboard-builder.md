# Skill: Excel Dashboard Builder

Use for internal reports, attendance summaries, payroll exports, class performance, and operations dashboards.

## Workflow

1. Define source data and required columns.
2. Validate rows and normalize dates, names, class codes, and statuses.
3. Create summary tables and calculated metrics.
4. Add charts only when they answer a real operational question.
5. Export stable Excel structure with clear sheet names.

## Output

```md
Inputs:
Validation:
Sheets:
Metrics:
Charts:
Export path:
Data quality notes:
```

## Rules

- Preserve raw data in a separate sheet when possible.
- Include skipped/invalid rows report.
- Use dry-run before overwriting existing files.
