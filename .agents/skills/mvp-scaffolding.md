# Skill: MVP Scaffolding

Use for quickly creating auth + dashboard, CRUD modules, role permissions, and report/export foundations.

## Default MVP Scope

- Auth and protected dashboard shell.
- Admin roles and permission checks.
- CRUD module with list, create/edit form, detail view, validation.
- Report/export path when needed.
- Minimal tests or manual checklist.

## Workflow

1. Inspect existing app structure.
2. Choose the smallest compatible stack.
3. Scaffold one vertical slice end-to-end.
4. Verify locally.
5. Document setup/env if needed.

## Rules

- No student role by default unless requested.
- Do not add payments/subscriptions unless explicitly requested.
- Keep MVP deployable on Vercel when possible.
