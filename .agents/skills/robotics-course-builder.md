# Skill: Robotics Course Builder

Use for robotics lessons, course modules, activities, rubrics, parent reports, and AI tutor content.

## Workflow

1. Identify age group, course level, duration, materials, and learning goals.
2. Build module structure: concept, demo, hands-on build, coding/task, reflection, assessment.
3. Produce teacher notes and student-friendly instructions.
4. Add safety notes and required materials.
5. Generate rubric and parent-facing summary.

## Output

```md
Course/module:
Age/level:
Learning outcomes:
Materials:
Lesson flow:
Assessment:
Teacher notes:
Parent summary:
```

## Tone

Friendly, academic, practical, parent-safe.
