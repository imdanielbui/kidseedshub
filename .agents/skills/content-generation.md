# Skill: Content Generation

Use for parent-facing messages, reports, course content, marketing copy, chatbot answers, and admin documentation.

## Workflow

1. Identify audience: parent, student, teacher, admin, customer, internal team.
2. Select tone: professional, friendly, academic, marketing.
3. Use actual source data; mark assumptions.
4. Produce concise, ready-to-send content.
5. Add review notes for sensitive claims.

## Output

```md
Audience:
Tone:
Content:
Review notes:
```

## Rules

- Do not invent student performance facts.
- Keep parent-facing content clear, positive, and specific.
- For marketing, optimize clarity and conversion without exaggeration.
