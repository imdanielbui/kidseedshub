# Skill: Spec-Driven Development

Use for broad features, unclear requirements, and multi-step product work.

## Workflow

1. Clarify the goal and constraints.
2. Write a compact feature brief.
3. Produce a technical plan.
4. Break into tasks.
5. Implement in small slices.
6. Verify against acceptance criteria.

## Output

```md
Feature:
Users:
Scope:
Out of scope:
Data/API impact:
UI impact:
Acceptance criteria:
Verification:
Risks:
```

## Rules

- Keep artifacts short and executable.
- Prefer traceability over prose.
- Use for auth, scheduling, reports, integrations, and multi-role CMS flows.
